# 🎵 Spotify & YouTube Performance Analytics Dashboard

An interactive **Power BI dashboard** built using **SQL, Power BI, and DAX** to analyze Spotify and YouTube music performance. This project explores artist performance, audience engagement, streaming trends, and audio characteristics to uncover actionable business insights.

---

## 📌 Business Problem

Music labels and artists need to understand:

- Which artists and tracks generate the highest streaming performance?
- Does YouTube engagement translate into Spotify streams?
- Do official music videos outperform unofficial uploads?
- Which audio features are associated with successful tracks?

This dashboard answers these questions through interactive visualizations and SQL analysis.

---

## 🛠️ Tools & Technologies

- **SQL (PostgreSQL/MySQL)** – Data exploration and business analysis
- **Power BI** – Dashboard creation and data visualization
- **DAX** – Calculated columns and measures
- **Figma** – Dashboard wireframing and layout design

## 🧠 SQL Analysis

Performed **22+ business-focused SQL queries** ranging from beginner to advanced concepts, including:

- Aggregate Functions
- Joins
- Subqueries
- Common Table Expressions (CTEs)
- Window Functions
- Correlation Analysis
- Ranking Functions

Some business questions answered include:

- Top-performing artists and tracks
- Correlation between YouTube views and Spotify streams
- Official vs unofficial video performance
- High-performing but underrated tracks
- Artist-wise streaming contribution
- Audio feature analysis

---

## 💡 Key Insights

- A small number of artists contribute a significant share of total streams.
- Official videos generally receive higher engagement than unofficial uploads.
- YouTube popularity shows a positive relationship with Spotify streaming performance.
- High danceability and energy do not always guarantee higher streams.
- Some tracks achieve high streams despite relatively low audience engagement, indicating playlist-driven success.
